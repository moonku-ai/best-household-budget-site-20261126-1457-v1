DompetKeluarga — buku kas keluarga Indonesia: dashboard sisa bulan berjalan, transaksi yang bisa ditambah/diubah/dihapus, anggaran per kategori, laporan dengan grafik, dan target tabungan dengan kalkulator. Situs statis yang bekerja offline di desktop dan ponsel; grafik SVG buatan sendiri, data tersimpan di localStorage, tanpa satu pun request jaringan.

## Run it

```sh
node serve.ts
```

Lalu buka http://localhost:8080.

## Penyerahan

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` menyalin `app/` dan `screenshots/` ke direktori keluaran dan menulis `dossier.json` dengan pustaka make.fun di `vendor/makefun-frontend.ts`.
